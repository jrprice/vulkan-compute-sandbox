# Reproducer for a Vulkan FP16 bug on Nvidia devices

The SPIR-V shader in `shader.spvasm` (compiled into `out.spv`) declares an array
of 128 fp16 elements in a uniform buffer and copies them to a storage buffer in
a loop. The input values are all initialized to `1.0h (0x3C00)` on the host.

The results should all be `1.0h (0x3C00)` when read back to the host, but on
Nvidia GPUs with driver 610.47 the last few values are incorrect. Using a
smaller array size (e.g. 112) does exhibit an issue.

## Building and Running

Build with CMake, then run the binary:
```
./vulkan_compute_test.exe out.spv
```
